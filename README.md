# CopyWP Scanner

V0.2.4 async scanner for CopyWP.

- Async scanning on Vercel
- WordPress callbacks support pretty REST URLs and `?rest_route=` URLs
- HMAC SHA-256 callback signing via `X-CopyWP-Signature`
- Bearer compatibility retained
- Automatic callback URL fallback for WordPress rewrite/permalink issues

Production deployment trigger: 2026-09-16 V0.2.4.
